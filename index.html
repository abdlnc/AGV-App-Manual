Field Operation Guide

AGV Robot Controller

How to connect to the robot, run it autonomously, fence and cover a field from the GPS map, and get at the maps and photos it saves — using the Android controller app.

Who this is for. Everything in this manual is a control an operator can reach from a normal install of the app. Bench-test and calibration controls are not covered.

01 Before you switch on

The phone talks to the robot over Wi-Fi. Both have to be on the same network, and the robot needs about a minute after power-up before it starts answering.

  1. Power the robot. Its software starts on its own — nothing to launch by hand.
  2. Put the phone on the same Wi-Fi network as the robot. There is no Bluetooth or direct-cable fallback.
  3. Have the robot's IP address to hand. It is the number you type on the first screen, and it can change when the robot joins a different network.
  4. So photos are tagged with a position, start the robot outdoors with open sky. A fix needs at least four satellites and usually takes a few minutes from cold.
  5. Wait roughly 60 seconds after power-up, then connect.

If a field boundary is saved on the robot, it will not drive itself at all — not in AUTO, not to a waypoint, not in COVER — until it has a GPS fix. Without a fix it cannot prove it is inside the field, so it holds still.

Clear the area first

Once you press START AUTO the robot drives off by itself. Stand clear of it, and keep the phone in your hand the whole time it is moving — the red stop button is the fastest way to halt it.

02 Connecting to the robot

The first screen does one job: point the app at the robot.

  1. Raspberry Pi IP Address. Replace the placeholder with the robot's actual address, for example 192.168.1.24. The app keeps no list of past addresses, so re-enter it each launch.
  2. CONNECT. Opens the control screen straight away, whether or not the address was reachable. Check the Wi-Fi icon at the top right of the control screen to see whether the link really came up.

If the icon shows as disconnected, the app keeps retrying on its own and the status line reads Reconnecting…. You do not need to back out and press CONNECT again unless you mistyped the address.

03 The control screen

This is where the robot is driven and watched. The live camera fills the screen, with status and controls layered over it.

  1. Mode indicator. Shows AUTO in amber while the robot is driving itself. It is a status marker, not a button — use the large button at the bottom to change mode.
  2. Run timer. Appears only while a run is being recorded, counting up from the moment the run started. The finished run lands in Run Logs. While the timer shows, the robot is saving photos.
  3. Top button bar. Left to right: Wi-Fi state (status only, not pressable), GPS Map, Lidar Map, Run logs, Saved Images, and the red Emergency Stop.
  4. Warning banners. Stack here when the robot sees something. They clear themselves — see the table below.
  5. Detection box. Drawn where the obstruction model found something, labelled Obstacle. The badge in the bottom corner gives the age of the reading; boxes fade from green to amber as they get stale and disappear entirely once too old.
  6. Status and fix. Connected, Disconnected or Reconnecting…, with the GPS fix quality and satellite count underneath.
  7. START AUTO / STOP AUTO. The main control. Starts autonomous driving, and stops it again.
  8. GPS chip. Reads GPS n sats in green on a good fix, or NO GPS n in view in grey while searching. A climbing count means the antenna is working.

Running the robot autonomously

  1. Check the Wi-Fi icon and the status line both show the robot is connected.
  2. Check the camera is live. If the screen reads NO CAMERA FEED, the view is replaced by a Lidar radar display, and the obstruction model has nothing to work from.
  3. Make sure nobody is standing near the robot.
  4. Press START AUTO. The robot drives forward and handles obstacles by itself; the mode indicator turns amber, the run timer starts, and the cameras start saving photos.
  5. Watch the banners while it runs. The robot stops, reverses and turns on its own — the banner says which it is doing.
  6. Press STOP AUTO to end the run. The timer stops, photo saving stops, and a confirmation of the logged run appears briefly.

If a field boundary is set, AUTO stays inside it: on reaching the stop line the robot stops, backs into the field and turns away. To work through the whole field in an orderly pattern instead of roaming, use COVER on the GPS Map (below).

One driving mode at a time

START AUTO, the map's GO and START COVER each take over the robot. Press STOP AUTO before using GO or START COVER, and stop those before pressing START AUTO. The control screen does not know about a map run, so its button can show START AUTO while the robot is busy with one.

Emergency Stop

The red button halts the robot at once, from any state — AUTO, a waypoint or COVER — and ends the run in progress. Use it rather than STOP AUTO whenever something is wrong — it takes one press from anywhere on this screen. On the GPS Map, use the red STOP button there, or go back to this screen.

What the banners mean

Banners stack top-centre with the most serious at the top, and each disappears on its own once the condition passes. They are all hidden while the app is disconnected.

04 The GPS Map

Opened with the map icon. Shows where the robot is on a street or satellite map, and is where you send it to a point, draw the field boundary, and run COVER.

  1. App bar. The layered-squares icon opens the tools and layers menu (below). It turns amber while you are setting a position or editing the boundary, as a reminder that taps on the map are doing that rather than setting a destination. The target icon is Follow robot: the map keeps the robot centred until you pan it yourself, and one tap brings it back.
  2. GPS card. Latitude and longitude to 6 places, heading, fix quality, satellites in use, and how many points the trail holds. With no fix it says acquiring GPS… and how many satellites are in view.
  3. Field boundary. The solid green outline is the boundary saved on the robot. The dashed amber line inside it is the stop line — the closest the robot will drive itself to the edge.
  4. COVER lanes. The route COVER plans through the field, in thin cyan. Shown only while a boundary is active.
  5. The robot and its trail. The green arrow is the robot, pointing the way it is heading. The thicker cyan line is where it has been since the map was opened.
  6. Pins. Red warning pins are spots where the Lidar saw something dangerously close — tap one for the direction, distance and time. Amber camera pins are saved photos; a number means several were taken there. Tap one to see them.
  7. COVER card. Appears whenever a boundary is active: START COVER, its progress, and STOP. See Covering the field.
  8. Waypoint panel. Tap the map to set a destination, then GO. See Driving to a point.

The GPS position is approximate

The robot's GPS can wander several metres even while it stands still, and more among houses and trees. Everything on this screen — the arrow, the boundary check, COVER's lanes — is only as good as that position. Keep well clear of hazards near the edge of the field, stay with the robot while it drives, and if the arrow is clearly in the wrong place, correct it.

Tools and layers menu

  1. Set robot position. Tell the robot where it really is when its GPS is off. Needs a connection. While you are doing it, the same entry reads Cancel setting position. See Correcting the robot's position.
  2. Edit field boundary. Draw, change or remove the boundary. The line underneath says whether one is active. While editing it reads Stop editing boundary, which leaves without saving.
  3. Satellite view / Street view. Switches the map background. Satellite makes field edges easier to see.
  4. Show or hide layers. Tick or untick the path trail, the Lidar obstacle pins and the photo pins; each shows how many it holds. If the photos could not be fetched, the entry says unavailable – tap to retry.
  5. Clear trail & Lidar pins. Empties both from the map. Greyed out when there is nothing to clear. Photos are not affected.

The map background is downloaded from the internet. If the phone's Wi-Fi has no internet connection the background stays blank, but the robot, boundary, lanes and pins are still drawn.

Driving to a point

  1. Tap the map where you want the robot to go. A red pin appears, with an amber line from the robot to it, and the panel shows the point's coordinates and distance.
  2. Press GO. The panel changes to ▶ NAVIGATING with the distance left, and the line turns green. The robot drives there by itself and steers around obstacles on the way.
  3. Within about 3 metres the panel reads ARRIVED ✓.
  4. Press STOP to halt it on the way, or CLEAR to remove the pin. Clearing the pin also stops the robot.

GO stays greyed out until the robot has a GPS fix and a pin is set. Tapping somewhere new while the robot is driving moves the pin, but the robot keeps heading for the old one until you press GO again. Driving to a point is not logged in Run Logs, and no photos are saved on the way.

With a boundary active, a point outside the boundary is refused: the robot stays where it is, even though the panel says NAVIGATING. Press CLEAR and pick a point inside.

Setting the field boundary

  1. Corners and stop line. Numbered amber dots are the corners in the order you added them. The outline turns red while the shape is not acceptable, and the dashed stop line appears once it is.
  2. Stop line distance and check. − and + move the stop line in or out, from 1 to 15 metres in half-metre steps (3 m to start). The line below gives the corner count and area, or says what is wrong.
  3. ROBOT HERE, UNDO, CLEAR. ROBOT HERE adds a corner at the robot's own GPS position. UNDO removes the last corner, CLEAR removes them all.
  4. SAVE. Sends the boundary to the robot. Greyed out until the shape passes the checks and the robot is connected.
  1. Open the menu and choose Edit field boundary. While editing, a tap on the map adds a corner instead of setting a destination. If a boundary is already saved, its corners are loaded so you can change them.
  2. Add the corners in order around the field. Either tap the map, or take the robot to each corner and press ROBOT HERE. ROBOT HERE uses the same GPS the robot steers by, so it usually lines up better than a tap on the map background.
  3. Set the stop line distance. Allow at least as much as the GPS can wander, and more next to ditches, roads or anything the robot must not reach.
  4. Watch the check line. A boundary needs at least 3 corners, edges that do not cross, an area between 100 m² and 1 km², and enough room left inside the stop line.
  5. Press SAVE. The robot checks it again and stores it. The map then shows the saved boundary in green with the stop line inside it, and the COVER card appears.

The boundary stays saved on the robot through power-off. To delete it, choose Edit field boundary, press CLEAR, then REMOVE BOUNDARY (it takes the place of SAVE when no corners are left).

What the boundary does

  • In AUTO, when driving to a point, and in COVER, the robot never drives itself past the stop line. In AUTO and COVER, on reaching it the robot stops, backs into the field and turns away.
  • A waypoint outside the boundary is refused.
  • With a boundary saved and no GPS fix, the robot will not drive itself at all.
  • It checks the robot's plain GPS position, not a position you set by hand.

Covering the field (COVER)

COVER drives the whole field in straight lanes along its long side, at most 6 metres apart, instead of roaming the way AUTO does. It needs a saved boundary — the COVER card only appears once one is active.

  1. Put the robot inside the field with a GPS fix, and check the card shows the plan, for example 6 lanes, about 14 min.
  2. Press START COVER. A run starts — the timer appears on the control screen, photos are saved, and it is logged in Run Logs as a COVER run.
  3. The robot works through the lanes, then makes a fill-in pass over any patches it missed, then drives back to where it started and stops there. It still avoids obstacles; avoiding them always comes before keeping to the lane.
  4. When the card says COVER complete, press STOP to end the run. The robot holds still until you do, and keeps saving photos.

Correcting the robot's position

Among houses or trees the GPS can put the robot tens of metres from where it really is. You can tell the robot its real position with two taps; it then tracks its own movement from there.

  1. Make sure the robot is not on a run — setting the position stops the robot and holds it still until you finish.
  2. Open the menu and choose Set robot position. The panel reads SET ROBOT POSITION • 1 of 2.
  3. Tap the map where the robot really is. An amber pin marks it, and the panel shows the robot's reply — how far its GPS was out, for example GPS was 6 m off.
  4. Now tap a point a few metres in front of it, the way it is facing (at least 1 metre from the first tap). The panel closes and the map follows the robot again.

A card above the waypoint panel then says what is carrying the position along:

  • Your position, tracked by lidar (green) — the Lidar can see walls, houses or fences around it and follows the robot's movement to within tens of centimetres.
  • Your position, corrected GPS (42s left) (amber) — in open ground the Lidar has nothing to follow, so the robot uses GPS shifted by the error it had when you tapped. GPS error drifts, so this lasts about a minute; then the robot goes back to plain GPS and you can set it again.

USE GPS on the card goes back to plain GPS straight away. CANCEL abandons the taps; a first tap left without its second is dropped by the robot after two minutes anyway. Setting a position clears the path trail, since the old trail was drawn from the uncorrected GPS. The field boundary keeps checking the plain GPS whatever you set here.

05 Lidar Map and saving maps

Opened with the radar icon. Shows the live Lidar scan and holds the controls for the robot's own built map.

  1. Radar view. The live Lidar scan around the robot. The amber dot at the centre is the robot, the faint rings are 1, 2 and 3 metres, and the red dots are returns — things the Lidar can see. Front is up.
  2. SAVE CURRENT MAP. Saves a picture of this radar view onto the phone. It is a screenshot of the display, and it only lasts for the current app session.
  3. SAVE SLAM MAP SNAPSHOT. Tells the robot to save its real built map, with the path it drove drawn on top. This is the one that lasts — it goes into the robot's gallery under the MAPS tab.
  4. RESET MAPPED AREA. Wipes the map the robot is currently building and starts it over. Asks for confirmation first. Snapshots you already saved are not touched.

Two different things called a map. Button 2 saves what you are looking at, to the phone, for this session only. Button 3 saves the robot's accumulated map of the area, to the robot, permanently. For a record of a field, use button 3.

Below the buttons, SAVED THIS SESSION lists the radar screenshots taken since the app opened. Tap one to view it, or CLEAR to empty the list.

06 Saved Images

Opened with the photo icon. Everything the robot has saved, served from the robot itself — so it only loads while connected. The cameras save photos only while a run is being recorded (AUTO or COVER); nothing is saved while the robot sits idle.

  1. Four tabs. CAPTURES — the plain photo of each obstruction found. DETECTIONS — the same photo with the detection boxes drawn on. SOIL — downward soil-camera snapshots, one a minute during a run. MAPS — the SLAM maps you saved.
  2. Coordinates on each thumbnail. Where the photo was taken, to 6 decimal places. A photo taken without a fix says so rather than showing a guessed position — the position is never carried over from an earlier reading.
  3. Delete. Removes the image from the robot, after a confirmation. For a capture or a detection it removes both halves of the pair, since they are the same moment. You can also long-press a thumbnail to delete it.
  4. Show on map. Opens the GPS Map centred on where the photo was taken. Greyed out for a photo with no GPS fix.

No repeat photos. The front camera does not save an obstruction it has already photographed nearby, or a near-identical picture; it keeps the clearer of the two. The soil camera still saves its photo every minute, but marks a repeat of the same spot with a grey DUP tag in the SOIL tab — a robot standing still makes a row of them.

Photos are grouped by run, newest first, with a heading for each. When there is more than one run, chips across the top show a single run. Older photos saved before runs were tagged are grouped by time instead, marked grouped by time.

SOIL tab filter. The soil camera's classifier marks each soil photo as soil or not soil. Chips at the top of the SOIL tab — ALL, SOIL, NOT SOIL and, for photos taken before the classifier ran, UNCLASSIFIED — show one group at a time, each with its count. Not-soil photos also carry an amber NOT SOIL tag on the thumbnail.

Swipe sideways in the viewer to move through the images, and pinch to zoom. If the grid says it cannot reach the gallery, the robot is not responding — check the connection and press RETRY.

Soil photos need nothing from you. While a run is being recorded, the downward camera saves one image a minute on its own, tagged with the position and with the time and coordinates printed on the picture. There is no button for it.

07 Run Logs

Opened with the timer icon. One entry per autonomous run, kept on the phone.

  1. Clear all logs. Deletes every entry, after a confirmation. There is no undo.
  2. Run in progress. Shown while a run is still being timed. The ticking clock is on the control screen, not here.
  3. A finished run. Duration, the date and the clock times, where it started and ended, the distance actually driven, and how far apart the two ends were in a straight line.
  4. Runs without a fix. Still recorded, with the duration intact and the positions marked as unavailable rather than filled in with a guess.
  5. Delete one run. The bin icon on a card removes that run straight away. A message at the bottom offers UNDO for a few seconds if you pressed it by mistake.

Runs are recorded automatically: one starts when you press START AUTO or START COVER, and closes when you press STOP AUTO, the STOP on the COVER card, or the Emergency Stop. Driving to a waypoint is not recorded as a run. They are stored on the phone, so they survive restarting the app but not reinstalling it.
